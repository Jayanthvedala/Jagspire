## Day 4 – Practical Security Understanding

Started connecting the basic concepts with practical security activities.

### Basic Networking

Learned the basics of:

- IP addresses – used to identify devices on a network.
- DNS – translates domain names into IP addresses.
- HTTP – used for communication between clients and web servers.
- HTTPS – secured version of HTTP using encryption.

### Wireshark

Learned the basic purpose of Wireshark as a network protocol analyzer.

Practiced understanding network traffic and common protocols such as:

- TCP
- UDP
- HTTP
- HTTPS
- DNS
- ICMP
- ARP

### Basic Log Analysis

Learned that logs contain records of activities generated by systems, applications, and networks.

Studied how logs can be used to:
- Identify errors
- Detect suspicious activity
- Monitor user activity
- Investigate security incidents

### System and Network Events

Learned about events such as:

- User login/logout
- Failed login attempts
- File access or modification
- Process creation
- Network connections
- Firewall alerts

These events can provide useful information when monitoring systems and investigating suspicious activity.
